Entry for [make.fun's "One Line, Zero Use: The Useless Superpower Sprint"](https://make.fun/bounty/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68) — one original line, at most 200 characters, describing a hilariously useless superpower.

> I can make any queue move faster, but only the one I'm not standing in.

`main.py` (Python 3, stdlib only) writes that line byte-exact to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`) and prints it. No network, no randomness.
